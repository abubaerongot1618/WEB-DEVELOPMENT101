# Riverside Bakehouse

##Project Overview
This is a static website built for Riverside Bakehouse, a family-run bakery based in Johannesburg. The project was developed as part of the WEDE5020 at the Independent Institute of Education(IIE).

##Pages Included
-**index.html**-Homepage featuring banner, brief introduction,  and featured products
-**about.html**- About us page with the bakery history, mission, vision and team
-**products.html**-Menu page displaying products by category
-**order.html**- Online ordering form allowing customers to select items, choose delivery/pickup, and select a payment method of their choice.
**enquiry.html**- Enquiry form for custom orders and catering questions
**contact.html**- Contact details and general enquiry form

## Notes
-This site was built using plain HTML, no CSS, as per assignment requirements
- An additional page(order.html) was included beyond the required minimum of 5 pages to support online ordering functionality.
